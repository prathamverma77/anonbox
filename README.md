# AnonBox - Anonymous Messaging Platform

Send and receive anonymous messages with ease!

##  Live Demo
[https://anonbox-ruby.vercel.app/](https://anonbox-ruby.vercel.app/)

##  Features
-  Secure authentication with email verification
-  Send/receive anonymous messages
-  Modern UI with Tailwind CSS
-  User dashboard with message management
-  Real-time updates
-  Responsive design

##  Tech Stack
- **Frontend:** Next.js 15, React, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, MongoDB, Mongoose
- **Auth:** NextAuth.js with JWT
- **Email:** Nodemailer
- **Deployment:** Vercel

##  What I Learned
- Building production-ready Next.js applications
- Implementing secure authentication flows
- Managing MongoDB with Mongoose ODM
- Handling Next.js 15 breaking changes
- CI/CD with Vercel
